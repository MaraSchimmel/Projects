This project is a basic wireframe viewer that renders 3D shapes and allows for interactive rotation. It reads shape data from .dat files provided in the directory, currently supporting two shapes: a cube and a house.

Requirements:
Pygame
NumPy

Run the program from the WireframeTurntable.py file, ensuring the directory structure places WireframeTurntable.py at the same level as the .dat shape files.

Controls:
1: View the cube
2: View the house
Arrow keys: Rotate the object
F: Flip rotation direction
R: Reset position
P: Pause/resume rotation
ESC: Exit the program
